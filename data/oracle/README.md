# data/oracle — эталонные кадры оригинала

Кадры снимаются с запущенной игры (DXWnd + dgVoodoo) по протоколу
`docs/ORACLE.md` и сравниваются с нашим рендером
`tools/re/oracle_compare.py`.

## Имена

```
level0_x200_z724_yaw90_20261022T2130.png
level0_x200_z724_yaw90_20261022T2130.json
```

`<уровень>_x<позиция>_z<позиция>_yaw<угол>_<UTC-время>.png` — чем короче и
однозначнее, тем лучше; состояние всё равно дублируется в sidecar.

## Sidecar (обязателен)

```json
{
  "level": "level0",
  "sbt_sha256": "…",
  "sbw_sha256": "…",
  "save": "saved0",
  "camera": {"pos": [0.0, 0.0, 0.0], "yaw": 90.0, "pitch": 0.0},
  "render": {"width": 320, "height": 200, "api": "dgVoodoo 2.7.3",
             "output_api": "d3d11", "scale": 1},
  "capture": {"mode": "fullscreen", "screen": [1920, 1080],
              "rect": [96, 0, 1728, 1080]},
  "frames_after_start": 180,
  "notes": "без ввода, HUD выключен/включён"
}
```

Без sidecar кадр нельзя ни воспроизвести, ни сравнить: HUD, оружие и анимации
зависят от состояния.

## Что коммитить

По умолчанию — только `README.md` и sidecar'ы; PNG-кадры попадают в git
только с разрешения пользователя (это не ассеты игры, но объём). Сами
файлы игры сюда не копировать.
