# NEXT — очередь автономной работы

Обновляется в конце каждого хода. Если пользователь не написал `STOP`/`пауза`,
агент берёт верхний незаблокированный пункт и работает дальше без разрешения.

## Правило конвейера (не останавливаться)

Работа идёт **волнами сабагентов**: после вливания очередной партии сразу
запускается следующая (2–4 независимые задачи, разные файлы). Простой
не допускается: если все текущие агенты ждут — берётся собственная задача
(аудит, доки, гейты) или запускается новая волна. Модель сабагентов —
разрешённая сессией (`opencode-go/deepseek-v4.1-flash`), провайдер явно.

Правила волны:
* каждый агент — свой worktree/ветка от master, только новые файлы +
  `engine/CMakeLists.txt`/`engine/tests/CMakeLists.txt` (общие `main.cpp`,
  `config.*`, `ROADMAP.md` — за основным агентом);
* сборка только своей цели (`--target ... -j 4`), полный `ctest` — на
  интеграции; `regress.py --mirror --json` — быстрый гейт агента;
* после отчёта: влить, собрать, прогнать полный `ctest` + `regress --full
  --mirror`, обновить `ROADMAP`/`JOURNAL`/`CURRENT_STATE`, запустить
  следующую волну.

## Директива (постоянная, переносить в каждое сжатие контекста)

- **Не останавливаться.** Пока есть незаблокированная работа — брать следующий
  пункт и продолжать; ожидание сабагента не повод закончить ход.
- **Держать сабагентов в работе.** 2–4 параллельно, свой worktree/ветка от
  master, только новые файлы; после вливания партии сразу заводить следующую.
- Модель сабагентов — только бесплатная; выбор за пользователем. Текущее
  разрешение сессии: `opencode-go/deepseek-v4.1-flash`.
- Ставить ✅ только по проверяемому результату, частичное — 🟡; обновлять
  `ROADMAP.md`, `docs/JOURNAL.md`, `NEXT.md` в конце хода.
