# Baseline: установка, инвентарь и регрессия

* **Дата:** 2026-10-19/20.
* **Тулкит:** commit `be4f75f` (+ этот файл).
* **Установка:** `D:\games\Gunmetal 3dfx` → `/mnt/d/games/Gunmetal 3dfx`
  (v1.36, 3dfx-сборка).
* **Воспроизведение:** `python3 regress.py --full` (пишет только в
  `/tmp/opencode/regress`, установку не меняет).

## Регрессия

`regress.py --full`: **83/83 проверок** за **~116 с** (быстрый прогон без
извлечения: **79/79 за ~80 с**; до оптимизации было 355 с / ~15 мин), exit code 0.
Что ускорено: `entities.py` больше не декодирует скрипт на каждую сущность
(индекс блоков вместо 45k декодирований: 132 с → 0.4 с), `sbc`/`sob` в быстром
режиме только парсят (`--check`), проходы по 36 уровням идут через пул процессов,
а четыре тяжёлые проверки извлечения запускаются параллельно.
Покрыты архивы BIGFILE
(чтение/запись/`set`), `.sbw`/`.sbt`/`.sbc`/`.sob`/`.soo`/`.sof`/`.sbm`,
скриптовая ВМ и сцена, сохранения (игрок, оружие/патроны, цепочка блоков,
`--set`), `.sml/.sme`, кампания, шасси, вещи, мелкие форматы, инвентарь.

## Манифест установки (`gm.py manifest`)

`docs/manifests/gunmetal-3dfx-136.sha256` — 2161 игровой файл (373.7 MiB),
формат `sha256sum` (проверяется из корня установки:
`sha256sum -c .../gunmetal-3dfx-136.sha256`). Сводный SHA-256 всех строк:

```
b1d6e04321e011e8ea52a96df9c9cb738dcd8e950ae2465c339af880308601e4
```

Исключены пользовательские данные (`SAVEGAME/`) и неигровые файлы (DXWnd,
html/jpg/png, архивы) — они видны в `gm.py manifest --all`. Любая подмена
ассета меняет сводный дайджест; конкретный файл находится повторным запуском
`sha256sum -c`.
