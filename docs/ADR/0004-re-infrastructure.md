# ADR 0004 — инфраструктура реверса: кэш, зеркало, бюджет контекста

* **Статус:** принято (2026-10-22, `M0.7`/`M0.8`).
* **Дата:** 2026-10-22.
* **Контекст:** цикл реверса упирался в две вещи, не связанные с самой игрой:

  1. `/tmp` здесь — tmpfs. `wsl --shutdown` стирал листинг `objdump` и копию
     `gundx.exe`; инструменты и часть `regress.py` падали, пока всё не
     пересоздавалось вручную. Сам листинг (14,6 МБ, 283 626 строк) ещё и
     парсился заново на каждый `exelib.disasm()` — ~100 мс на запрос.
  2. Установка лежит на `/mnt/d` (drvfs/9p): обход 4215 файлов — 7,1 с,
     `sob --check` — 1,5 с. Плюс документация ~2,5 МБ, которую агент не должен
     читать целиком ради одного адреса.

## Решение

1. **Постоянный кэш** `~/.cache/gunmetal-re` (`GUNMETAL_CACHE`), на `/dev/sdd`:
   листинг, `gundx.asm.idx` (VMA + смещения строк), копия exe, зеркало игры.
   `exelib` строит листинг сам, индекс инвалидируется по size/mtime,
   `disasm()` читает только запрошенный диапазон.
2. **Зеркало установки** с манифестом (size/mtime/sha256) и `regress.py
   --mirror`: сверка при запуске (кэш проверки 15 мин), автоСинхронизация при
   расхождении. Зеркало — кэш, а не источник истины; игра только читается.
3. **Точечный контекст**: `tools/ctx.py` (`doc`/`addr`/`find`/`outline`/`task`,
   лимит 40 строк) и `docs/INDEX.md`; большие доки читаются разделами.
4. **Регистронезависимые пути** в регрессе (`gp()`): drvfs не различает
   регистр, ext4-зеркало — различает; проверка на зеркале это выявила.

## Почему не альтернативы

| Вариант | Причина отказа |
|---|---|
| держать листинг в `/tmp` | tmpfs стирается при `wsl --shutdown`, теряется между сессиями |
| копировать установку в git/`build/` | ассеты игры не коммитятся; зеркало — кэш, его можно пересоздать |
| читать доки целиком | `FORMATS.md` 207 КБ ≈ десятки тысяч токенов на один вопрос |
| распараллелить всё сильнее | 16 воркеров уже оптимум на 32 ядрах, дальше растёт RSS |

## Последствия

* Первый запуск платит за сборку кэша (~0,3 с листинг+индекс, ~65 с зеркало);
  дальше — секунды. Замеры: `regress.py` 79 с → 46 с, inventory 7,1 → 0,14 с,
  `disasm` 100 мс → 0,02 мс.
* Появился ещё один каталог состояния (`~/.cache/gunmetal-re`); его потеря
  безопасна — всё пересобирается, манифест и `selftest` проверяют целостность.
* Методика и чеклисты — `docs/RE_METHOD.md`; правила — `AGENTS.md`.
