# ADR 0003 — сохранения: читать оригинал, писать совместимо где возможно

* **Статус:** предложено, ждёт подтверждения (`ROADMAP.md` D5, §11.5).
* **Дата:** 2026-10-19.
* **Контекст:** оригинальный сейв — это пара `savegame/saved<N>.sbt` +
  `saved<N>.sbw`. `.sbw` — обычный мир уровня; `.sbt` — контейнер
  `A SAVED GAME` с встроенным скриптом уровня и хвостом блоков состояния
  (`FORMATS.md` §16). Тулкит умеет читать игрока, оружие/патроны, двери,
  переключатели и править их (`gm.py save --set`).

## Решение

1. **Чтение оригинальных сейвов — обязательное** и уже покрыто регрессией
   (`saved0`/`saved1`).
2. **Запись — в формате оригинала, насколько это достижимо.** Правка
   выполняется на уровне байтов в уже найденных блоках (смещения вычисляются
   заново на каждом запуске), потому что хвост — сырые рантайм-структуры.
3. **Чужой/неизвестный сейв не перезаписывается**: по умолчанию — сухой
   прогон, запись только в `--out` (копия) или по явному `--inplace`.
4. Если полная совместимость окажется недостижимой (например, блоки, которые
   оригинал пишет только при определённых условиях), собственный формат
   должен быть версионирован, документирован и открываться тулкитом.

## Почему не «свой формат сразу»

* Оригинал — единственный оракул геймплея; сейвы нужны для дифференциальных
  тестов (`savediff`, сверка состояний).
* Побайтовая правка уже проверена: `armor`, `ammo`, `selected`, `mask`,
  `shield`, `door` (`gm.py save --set`), значения клампятся по лимитам уровня.

## Границы

* Установка игры — read-only (ADR 0002, D1); все записи — в отдельный каталог.
* Правка не «чинит» блоки, чья раскладка ещё не разобрана (префикс потока
  отсутствует в реальных сейвах; блок `3` — слоты вещей, разобран только
  как набор записей).
