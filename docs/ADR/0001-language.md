# ADR 0001 — язык и стек целевого движка

* **Статус:** предложено, ждёт подтверждения (см. `ROADMAP.md` §11.1).
* **Дата:** 2026-10-19.
* **Контекст:** `gm.py` — эталонный тулкит на Python; ему нужно читать
  оригинальную установку и служить оракулом. Игровой runtime на Python
  невозможен: 320×200 / 640×400, 8-битный палитровый растеризатор, 60 FPS,
  x87-последовательности оригинала.

## Решение

**C++20 + CMake + SDL3**, два рендер-бэкенда:

* `sw` — программный 8-битный палитровый растеризатор, максимально близкий к
  оригиналу (эталон паритета);
* `gl` — GPU-бэкенд для высоких разрешений (не обязателен для parity).

Python-тулкит остаётся второй реализацией и генератором тестовых векторов
(`ROADMAP.md` D2).

## Почему не альтернативы

| Вариант | Причина отказа |
|---|---|
| Python + C-расширения | 60 FPS и детерминизм дороже, чем выигрыш в скорости прототипа |
| Rust + wgpu | структуры Watcom-кода (`struct`/`union`, x87) переносятся в C++ прямее; команда не выбрана |
| C + SDL2 | C++20 даёт RAII/шаблоны без потери контроля над раскладкой структур |

## Последствия

* Нужны `static_assert` на размеры/смещения структур и общая схема форматов.
* x86-эмулятор (`tools/re/emu.py`) остаётся оракулом для спорных мест.
* Решение фиксируется здесь; если язык меняется — меняется целиком, а не
  наполовину (`ROADMAP.md` D0).
