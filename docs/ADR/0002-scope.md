# ADR 0002 — что считается «готовым движком»

* **Статус:** предложено, ждёт подтверждения (`ROADMAP.md` §11.2–11.5).
* **Дата:** 2026-10-19.
* **Контекст:** «готовый движок» можно понимать как asset-complete runtime
  (читает установку, но без геймплея) или как полностью проходимую игру.

## Решение

Цель — **полный игровой цикл** (`ROADMAP.md` §1.2), а не только просмотрщик.
Минимальные проверяемые критерии:

1. Запуск на чистой машине с оригинальной установкой v1.36, без конвертации.
2. Кампания `level1…level24` + штабы + секретные уровни + финал; переходы
   совпадают с таблицей `FORMATS.md` §15.
3. Чтение оригинальных `saved<N>.sbt/.sbw`; запись — в совместимом формате
   настолько, насколько это достижимо (свой формат допустим, если
   версионирован и документирован).
4. Все поставочные ассеты либо используются, либо явно задокументированы.
5. Нет «тихих» пропусков: ошибка ассета — понятная диагностика.

## Вне цели

Ремастер, новые ассеты, VR, мобильные платформы, побитовый паритет x87 вне
геймплея, распространение оригинальных данных, полная совместимость с
DirectPlay-клиентом (stretch).

## Последствия

* «Готово» проверяется командой/тестом, а не ощущением.
* `.sou` (Miles ADPCM) — единственный риск, где данных может не хватить;
  fallback — тишина с предупреждением, а не PCM-мусор.
* `gm.py` не выбрасывается: он остаётся оракулом и инструментом моддинга.
